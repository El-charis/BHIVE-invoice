# BHIVE Invoice Management Portal

BHIVE Invoice Management Portal — invoice generation, backend tracking, clients and dashboard.

## Stack
- HTML/CSS/JavaScript
- Supabase Auth + PostgreSQL
- Vercel

## Core rules
- Manual entry first
- Calendar-date based week grouping
- VAT: 7.5%
- BHIVE Resource Intl LTD bank details
- Invoice history and backend event tracking
